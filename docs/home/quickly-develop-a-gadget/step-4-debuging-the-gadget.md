# 步骤四：调试小程序


在小程序开发完成后，你可以先将小程序发布到测试版应用中进行测试。
## 步骤一：真机调试

1. 打开移动端Lark，切换到测试企业。

2. 打开Lark开发者工具，然后在左上角单击**真机调试**，然后使用移动端Lark扫描弹出的二维码。

	手机需要与开发者工具处于同一网络才可以进行真机调试。
  
## 步骤二：发布测试版小程序

1. 打开小程序开发工具。

2. 单击右上角 **上传**，然后在弹出的页面中选择 **平台** 和 **版本号**，最后单击 **上传** 按钮完成上传。

	![image.png](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/387331333cf217aafe48bf938ffc9b7a_EdN450zWlY.png?height=896&lazyload=true&maxWidth=600&width=1802)

3. 登录[开发者后台](https://open.larksuite.com/app)，进入测试版应用详情页，单击 **小程序** 进入小程序页面。

4. 选择小程序 **版本号** 和 **最低兼容Lark版本** ，然后单击 **保存**。

	测试版应用无需发布即可直接在测试企业的工作台进行测试和验证。
