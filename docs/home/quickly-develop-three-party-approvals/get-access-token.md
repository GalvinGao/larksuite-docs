# 获取访问凭证
在调用服务端API之前，应用需要从Lark开放平台获取相应的访问凭证(access_token)。访问凭证代表应用从平台、租户、用户手中获得的授权。在本教程中，你需要获取应用的`tenant_access_token`。

# 操作步骤
:::html
<md-td>
1. 打开[API调试台](https://open.larksuite.com/api-explorer)。

2. 在左上角单击**切换应用**，然后在弹出的对话框中选择[已创建的应用](/document/home/quickly-develop-three-party-approvals/creating-applications-and-requesting-permissions)，最后单击**确定**完成切换。
    
    <img src="//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/4a75a0dc0f5a3176f9b59f809390ec96_iJvfyThIiQ.png?lazyload=true&width=2720&height=1868" style="width:70%"/>

3. 在左侧查看鉴权凭证栏，获取**tenant_access_token信息**。

    <img src="//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/ff92622aca13e9bbb688e1f637c38f50_ZlrTFKceVj.png?lazyload=true&width=878&height=1330" style="width:30%"/>
  
</md-td>
:::
