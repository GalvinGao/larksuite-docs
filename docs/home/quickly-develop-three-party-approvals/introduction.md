# 简介
## 业务场景

中大型客户拥有多套审批系统时，可选用三方审批汇总多系统的数据。无需跨平台，无需反复迁移数据，用户在Lark中即可统一处理信息，享受一站式的办公体验。
![](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/0ea8838fba331ba56ab1d11f7cfeff2f_bzuXMxfJ7Z.png?lazyload=true&width=1640&height=888)
本示例介绍如何使用Lark审批提供的 OpenAPI，将三方审批系统对接到Lark审批系统中，并同步消息到Lark审批系统中
