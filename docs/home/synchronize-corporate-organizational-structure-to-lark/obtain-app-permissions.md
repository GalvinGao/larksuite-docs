#  开启应用权限
从上述所需方法可看到如需调用这些API，需要提前获取应用权限：

-  [应用权限](/document/ukTMukTMukTM/uQjN3QjL0YzN04CN2cDN) 中必须选择 `更新通讯录` 权限；



##  申请应用权限
应用权限由应用开发者在开发者后台申请，选择你所创建的应用，在应用详情页面点击左侧导航栏的权限管理，在权限选择框中输入所需权限并点击开启。

![image.png](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/6005716f4462444be99a339a2e076203_bgboAfBw1e.png?lazyload=true&width=2794&height=1626)

权限的开启，需要提交版本发布，对于企业自建应用，管理员审核通过后权限即可生效。

![image.png](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/010dd0525aff29ebdd82f975a239f2fc_BcZMNkh0ps.png?lazyload=true&width=2784&height=1618)

对于还在开发阶段的应用，我们提供了「测试企业与人员功能」，开发者可以使用测试版应用，此版本中涉及的权限和配置变更都会直接生效，无需管理员审核，如下图：

![image.png](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/d88cbfba6b3fbf352d124682f3f94b39_berlVCWYN5.png?lazyload=true&width=2790&height=1294)

具体开通流程参照[测试企业与人员功能](/document/home/introduction-to-custom-app-development/testing-enterprise-and-personnel-functions)

开通测试企业与人员后，参照上述流程申请的权限就可以立即生效。
