# 步骤四：体验效果

在本步骤，你将使用示例代码对部门进行操作，然后进入Lark管理后台查看部门信息，最终在部门中添加一个新用户验证回调事件。


## 操作步骤

:::html
<md-td>
1. 打开本地终端工具，参考以下视频对部门进行增删改查操作。

	<md-video src="//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/fbde84dcb693208cfc57fac841a159d4_Yb932ksVwI.mp4"/>


2. 登录[Lark管理后台](https://www.larksuite.com/admin)，进入**组织架构** > **成员与部门** 页，查看刚刚操作过的部门。
  
	如下图所示，对部门的操作已成功。
    
    ![](https://sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/ark/398df44083dc89ab84ba887c17ce38f8.png?height=1354&lazyload=true&maxWidth=600&width=2574)

3. 选择子部门，单击 **添加成员** ，添加一个新用户。

    ![](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/9d2aea509c1892a4be95210afc4377fd_bxGLJoruxM.png?height=1178&lazyload=true&maxWidth=600&width=2176)

4. 返回终端工具，如下图所示已成功接收员工入职事件。

    ![](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/f9fed27af6619c5f128693ab92f62eb2_Hq4AvzgXF2.png?height=578&lazyload=true&maxWidth=400&width=1628)
  
</md-td>
:::
