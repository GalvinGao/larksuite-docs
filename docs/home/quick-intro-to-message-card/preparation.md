# 准备工作

在开始本教程之前，你需要完成以下准备工作：
- [创建](https://www.larksuite.com/hc/en-US/articles/360023713853)或[加入](https://www.larksuite.com/hc/en-US/articles/360043257294)Lark企业。

- 拥有一个可以接收事件消息的服务端地址，用于接收[卡片消息回调](/document/ukTMukTMukTM/uYzMxEjL2MTMx4iNzETM)。
