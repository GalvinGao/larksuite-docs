# 步骤二：创建多维表格

在本步骤，你将创建一个新的多维表格，并获取其App_token用于后续接口调用。
## 操作步骤
1. 使用[步骤一](/document/home/agile-project-cycle-management-based-on-bitable/prep-work)创建的测试租户，登录[Lark云文档](https://larksuite.cn/drive/home/)。
2. 在页面右上角单击 **新建** ，选择新建 **多维表格** 。

 	 ![图片](https://sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/ark/b692c6dd64cfff606bb7ad31c83c52cc.png?lazyload=true&width=1888&height=1126)

3. 选择空白模板，单击 **+** 。
  
 	 ![图片](https://sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/ark/4c68960ee741e312093c0a14a8c5ad64.png?lazyload=true&width=1932&height=1380)

4. 在浏览器顶部地址栏，复制多维表格的 **AppToken** 。
  
 	 ![图片](https://sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/ark/ab26c46827361f913fc6b9e7ffd5ac7b.png?lazyload=true&width=2420&height=744)

5. 在多维表格表格右上角依次选择 `···` > **更多** > **添加文档应用** ，在弹窗中搜索[步骤一](/document/home/agile-project-cycle-management-based-on-bitable/prep-work)创建的应用名称，赋予其 **可管理** 权限。
  访问应用非自有资源时，应用必须拥有该资源的管理权限，并且需要开启机器人能力。

  	![图片](https://sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/ark/7e516dfdaeb115c8cb20aff8344553c7.gif?lazyload=true&width=1202&height=854)
