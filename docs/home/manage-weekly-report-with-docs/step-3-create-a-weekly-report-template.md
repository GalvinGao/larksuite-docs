# 步骤三：创建周报模版

在本步骤，你将创建一个新的周报模板文档，并获取其 **file_token** 用于后续接口调用。

## 操作步骤
:::html
<md-td>
1. 使用[步骤一](/document/home/management-weekly-report-based-docs/step-1-create-and-configure-an-application)创建的测试租户，登录[Lark云文档](https://larksuite.com/drive/home/)。
2. 在页面右上角单击 **新建** ，选择 **文档** 。
    
	<img src="//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/c5b0106a8bb2b8196f5db86c22bdf6b6_HfFm5F8eON.png?lazyload=true&width=2554&height=1428" style="width:70%"/>
  
3. 在模版分类中选择选择 **日常工作** ，选择 **工作周报** 模版，单击 **使用** 创建文档。
  
	<img src="//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/597765c2c5b2c7c9240cae852743f371_466r3SxAjK.png?lazyload=true&width=2538&height=1822" style="width:70%"/>
  
4.  在浏览器顶部地址栏，复制模板文档的 **file_token** 。
  
	<img src="//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/33c7f5dc4442791045af7b2f4dcfa337_TnCyCII1rM.png?lazyload=true&width=2540&height=1400" style="width:70%"/>
  
5.  在模版文档右上角依次选择 `···` > **更多** > **添加文档应用** ，在弹窗中搜索[步骤一](/document/home/management-weekly-report-based-docs/step-1-create-and-configure-an-application)创建的应用名称，赋予其 **可阅读** 权限。


    需要将已创建的应用添加为周报模板文档的协作者，否则无法使用该模板创建新的周报文档。

  
	<img src="//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/669ddfcccc9d19677ae34e858e8ddedb_Q9JtRMsy3O.gif?lazyload=true&width=1676&height=1238" style="width:70%"/>
  
  
  
  
</md-td>
:::
