# 步骤五：体验效果

在本步骤，你将在Lark客户端查看和验证示例代码运行后生成的消息通知提醒。

## 操作步骤

1. 打开桌面端Lark客户端，进入接收消息通知的群组。

	如下图所示消息通知已成功发送。

    ![image.png](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/7faaf8ce9ef2ca5a16a8b47b3586ae02_qiuHvCTlD8.png?lazyload=true&width=1766&height=1182)
    
    
2. 单击消息中的文档链接，打开云文档。

	如下图所示，周报文档位于周报知识库，并且已经为所有群成员添加了编辑权限。
