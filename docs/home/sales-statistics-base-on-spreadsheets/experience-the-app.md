# 发布&体验应用

1. 点击**版本管理与发布**，创建版本并发布上线。

    -   点击**创建版本**，填写发版必须内容，点击**保存**，完成版本创建。
    -   点击**申请发布**，应用即时上线生效。

    :::note
    - 本次涉及需要审核的权限，可以利用[测试企业与人员功能](/document/home/introduction-to-custom-app-development/testing-enterprise-and-personnel-functions)，生成测试版应用（无需发布，配置直接生效），完成测试。
    - 成功发布后，可以根据是否能搜到机器人，判断用户是否在机器人可用性范围内。
    :::
