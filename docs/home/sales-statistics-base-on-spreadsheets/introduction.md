# 简介
本示例介绍如何使用Lark电子表格的开放能力实现将外部销售额数据同步到电子表格中并进行总额统计的功能演示。主要流程：
- 获取应用云空间目录。
- 通过电子表格创建接口在目录中创建出新的电子表格。
- 通过电子表格写入数据接口将数据写入电子表格中，并添加SUM统计公式。
- 通过电子表格设置样式接口调整标题栏和数据区域展示样式。
- 通过添加协作者权限接口给指定用户开放阅读编辑权限。
