# 步骤二：添加机器人到群
在本步骤，你需要将已创建的机器人应用添加到用于接收周报通知的群组。
## 操作步骤
:::html
<md-td>
1. 打开Lark客户端，切换至测试企业。
  
	<img src="//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/fe000dbf4dd4043c5a73ff4a4dd5dff6_X3PUzeUqUe.png?lazyload=true&width=2202&height=1658" style="width:70%"/>
  
2. 创建一个用于测试的群组。
  
3. 在群组右上角依次选择 **`···`** > **设置**，在**设置**页面单击**群机器人**。

	<img src="https://sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/ark/92330c751d32319055901f0dca6c2307.png?lazyload=true&width=1776&height=1468" style="width:70%"/>
  
4. 单击 **添加机器人** ，弹出的对话框中搜索机器人名称，单击 **添加**。

	<img src="https://sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/ark/69a2a757863f6f1abf870bf4f51365e5.png?lazyload=true&width=1522&height=1146" style="width:70%"/>

  	添加成功后，你可以在群机器人页面进行查看。

	<img src="https://sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/ark/a6dbdc277e40c30dd8c06c4b71bbdb04.png?lazyload=true&width=1778&height=964" style="width:70%"/>

</md-td>
:::
