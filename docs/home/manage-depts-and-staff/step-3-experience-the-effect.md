# 步骤三：体验效果

:::note
对于测试版应用来说，仅测试企业的 **创建者** 及 **测试人员** 可以访问该应用。
:::

1. 登录Lark，并进入Lark工作台打开测试应用。 


2. 使用应用（人员部门管理）。

    在Lark工作台内打开应用时，可以在应用右上角获取到用户信息。
    
    ![](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/d53da62b88ecdbb7d3ddac243f1e0280_E5cgKePYfA.png?height=648&lazyload=true&maxWidth=600&width=1304)

3. 在应用右上角，单击浏览器打开图标。

    ![](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/9bd2b6e01232ef11f2a18c1af2121e72_wskTD38430.png?height=648&lazyload=true&maxWidth=600&width=1316)

4. 通过浏览器访问网页应用。

    - 由于浏览器获取不到 window.h5sdk，无法通过免登流程获取用户信息，会出现如下图的提示。

      ![](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/3cdca6c677fd0f8591ebf85931b10cf8_9vAF2ntGy9.png?height=220&lazyload=true&maxWidth=600&width=1138)

    - 浏览器访问方式和Lark工作台访问方式相比没有通过免登流程，获取不到用户信息，因此在页面右上角展示的是示例代码内的 React 框架图标。

      ![](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/8ac9976410b577b7e1b2a98e915d255e_vjzgmUxk6Q.png?height=640&lazyload=true&maxWidth=600&width=1286)
