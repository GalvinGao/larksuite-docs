# 步骤七：体验效果

:::note
对于测试版应用来说，仅测试企业的 **创建者** 及 **测试人员** 可以访问该应用。
:::

1. 打开Lark工作台，在搜索框中搜索应用名称，点击搜索结果打开应用。


2. 在 **部门管理** 页签，进行部门的增删改查操作，并在 **企业管理后台** > **组织架构** 中看到实际效果。

	- 增删改操作。

		![](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/6f6df5139a0a35ecfa5091b357fc6b47_4P7z7KsBr0.png?height=1400&lazyload=true&maxWidth=800&width=2874)
    
    - 查看实际效果。
    
		![image.png](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/f08f04fe1d3f535049394af5d5f29211_2Dc46Ks8e4.png?height=1108&lazyload=true&maxWidth=800&width=2878)

3. 在 **审批** 页签，提交请假或加班申请，审批通过后，可点击同步到日历，并支持导出数据。

	- 同步日历示例。

		![](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/004454491c71209fd075914f5b502088_ofR0L0t1Aw.png?height=880&lazyload=true&maxWidth=800&width=1952)
    
    - 数据示例。
    
		![image.png](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/24c27f1035535963aeb8d4b3a81e3fd6_3hORzZojoh.png?height=860&lazyload=true&maxWidth=800&width=2860)

4. 在 **企业管理后台** > **组织架构** 中添加或删除成员时，在 **人员管理** 页签可以同时接收到人员入职、离职事件。
