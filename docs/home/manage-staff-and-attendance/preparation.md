# 准备工作

在开始本教程操作步骤之前，你需要完成以下准备工作。

- [创建](https://www.larksuite.com/hc/en-US/articles/360023713853-create-organizations) 或 [加入](https://www.larksuite.com/hc/en-US/articles/360043257294-join-organizations)Lark企业。

- 本教程提供基于 Node.js 的[示例代码](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/9c5f7ad78a14ce4d9450484865d9339c_FYCFVidH7I.zip)，你需要在本地安装  [Node.js](https://nodejs.org/) 开发环境，安装 Node.js 的同时会自动安装 npm。
