# 步骤五：体验效果

:::note
对于测试版应用来说，仅测试企业的 **创建者** 及 **测试人员** 可以访问该应用。
:::

1. 打开**Lark客户端**，切换至测试企业。
  
2. 在**Lark客户端**搜索**机器人名称**，点击进入机器人对话框。

     ![](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/666b3a719ccce4f86b81c59e8b6a9c87_9grGNjZRhW.png?height=588&lazyload=true&maxWidth=600&width=1924)

3. 向机器人发送消息 **请假** ，等待响应。

    如下图所示，审批创建成功。

     ![](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/3a58cb71ca9767f8187d5b4cbe653b61_mWkyS6M2l8.png?height=1454&lazyload=true&maxWidth=600&width=1366)

    如下图所示，日程创建成功。

     ![](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/0c111dd8764fa7b944ba5381469765b3_AJZuA9Nk21.png?height=1418&lazyload=true&maxWidth=600&width=2022)

    如下图所示，机器人成功回复审批处理结果。

     ![](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/c43358056c31b38705064ad3648b33c1_qxvyhI3Zx3.png?height=1436&lazyload=true&maxWidth=600&width=2168)

4. 向机器人发送消息 **今晚加班两小时** ，等待响应。

    如下图所示加班日程已创建。

     ![](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/808def90281dcd16c5d364660dbc3206_oAdgiskYJW.png?height=1188&lazyload=true&maxWidth=600&width=1726)

    如下图所示机器人成功回复加班申请处理结果。
    
     ![](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/519fa1eb1846ed232c4721b87f008e88_HqR5v8kJpH.png?height=1312&lazyload=true&maxWidth=600&width=1922)
