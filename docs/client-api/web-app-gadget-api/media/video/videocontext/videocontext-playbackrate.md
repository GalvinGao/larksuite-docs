# VideoContext.playbackRate(number rate)

设置视频倍速播放

## 支持说明

| 应用能力 | Android | iOS | PC | 预览效果 |
| --- | --- | --- | --- | --- |
| 小程序 | <md-version>V6.1.0+</md-version> | <md-version>V6.1.0+</md-version> | <md-version>V6.1.0+</md-version> | <md-preview-app type="gadget" appId="cli_9dff7f6ae02ad104" path="/page/component/pages/video/video" fontSize="14">预览</md-preview-app> |
| 网页应用 | **X** | **X** | **X** | <md-preview-app type="webApp" appId="cli_9dff7f6ae02ad104" fontSize="14" disable=true>预览</md-preview-app> |


## 输入

| 名称 | 数据类型 | 必填 | 默认值 | 描述 |
| --- | --- | --- | --- | --- |
| rate | number | 是 |  | 倍速值，范围[0.5, 2]。<br>若传入值小于0.5，则为0.5；若传入值大于2，则为2；向下取整保留1位小数 |



## 输出
无
