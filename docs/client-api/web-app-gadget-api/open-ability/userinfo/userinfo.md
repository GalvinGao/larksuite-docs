# `UserInfo`

用户信息

## 属性列表
名称 | 数据类型 | 描述
--|--|--|--|--
`nickName` | `string` | 用户昵称
`avatarUrl` | `string` | 用户头像
`gender` | `number` | 用户性别
`country` | `string` | 用户所在国家
`province` | `string` | 用户所在省份
`city` | `string` | 用户所在城市
`language` | `string` | 所在地区所用的语言

### gender的合法值
值  | 描述
--|--|--|--|--
`0` | 未知
`1` | 男性
`2` | 女性

### language的合法值

值  | 描述
--|--|--|--|--
`en_US` | 英文
`zh_CN` | 中文
