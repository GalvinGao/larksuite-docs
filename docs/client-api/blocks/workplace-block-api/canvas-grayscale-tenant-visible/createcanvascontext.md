# canvasCanvasContext

## CanvasContext tt.canvasCanvasContext(string canvasId)

创建 Canvas 绘图上下文的 CanvasContext 对象。

## 参数说明


|**属性**|**类型**|**默认值**|**必填**|**说明**|**最低版本**
|:-|:-|:-|:-|:-|:-|
| canvasId | string  | -      | 是       | 画布标识，传入 canvas 组件的 canvas-id 属性|1.6.0

## 返回值

CanvasContext
