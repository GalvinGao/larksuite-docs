# Lark 开放能力能为企业带来什么？


Lark能力全面深度开放，作为信息的枢纽、业务的入口融入企业现有 IT 生态，良好地支撑和补充已有 IT 系统，提升企业数字化效能，助力企业打造**一站式协同专属平台**，让企业员工专注业务、工作更简单，让 IT 人员敏捷开发、体验更愉悦。

![图片](https://sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/ark/0edf16e890746cafc12a1e08bdb6391e.png?height=774&lazyload=true&maxWidth=700&width=2204)

用Lark开放平台集成企业现有系统，可以快速打破系统间的壁垒，让信息传递更高效。企业可以在现有系统和新建应用中调用Lark文档、通讯录、消息、用户名片等多个Lark模块能力，高效协同不止于Lark。

![image.png](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/136008599535291e9ea5fe64b72b5766_yFkWHgUdcu.png?height=1112&lazyload=true&maxWidth=700&width=2202)

我们为企业提供了多样的集成方案，以丰富灵活的开放能力满足企业的定制化需求，满足复杂业务场景，支持集成 CRM、OA、ERP、财务等场景，帮助打通业务系统和用户的最后一公里，助力企业实现数字化升级。

# 应用场景
## 用「机器人+消息卡片」实现业务消息高效流转

[Lark机器人](/document/uAjLw4CM/ukTMukTMukTM/bot-v3/bot-overview)可以与Lark日历、审批、云文档等应用、第三方主流业务系统、企业自建系统打通，通过向用户发送消息卡片的形式，在Lark中实现一站式聚合各类应用的通知、报警。比如，可与企业已有业务系统集成，发送监控告警、待办事项提醒、公司活动通知、数据日报推送、库存预警等。

[消息卡片](/document/ukTMukTMukTM/uczM3QjL3MzN04yNzcDN)是一种可以承载丰富的图文内容和交互行为的消息类型。通过消息卡片您可以获得以下能力：
* 使用消息卡片提供的富文本样式、图文布局模块，发送**样式精美**的卡片，比如醒目的通知、图文并茂的文章列表等，让重要的信息更好地触达用户。
* 使用消息卡片提供的**交互组件**，使用户无需离开聊天会话，就能快捷完成 OA 审批、投票统计、报警处理等系统操作。

## 丰富的开放能力与组件，支撑企业的多样集成诉求

企业可以在现有系统和新建应用中调用Lark文档、多维表格、通讯录、消息、任务、用户名片等多个Lark模块能力。已开放和支持的能力可参考[开放平台官网](https://open.larksuite.com/) 的「**开放能力列表**」。

除了丰富的 [服务端 API](/document/ukTMukTMukTM/uYTM5UjL2ETO14iNxkTN/server-api-list)，Lark还提供了多种应用能力，以支撑企业内不同诉求。我们常看到的**工作台**中一系列应用均为Lark小程序或Lark网页应用（比如审批、Lark帮助中心、汇报等）。
Lark可以集成多种类型的应用：
* 使用原生 H5 进行开发的 **网页应用。**
* Lark独创的轻量级功能块 **工作台小组件。**
* 使用Lark DSL 开发的 **小程序**，拥有前端开发经验的同学可以快速上手。

更多介绍内容，参考[应用能力简介](/document/home/app-types-introduction/robots-web-applications-and-mini-programs)。


# 服务与支持

* **获取技术支持**：点击官网任意页面的右下角的技术支持按钮，即可咨询开发过程中的问题，技术同学1对1协助你解决。

* **文档问题反馈**：如果你在开发过程中发现开发文档有错误，你可以直接在文档页面划词反馈，内容将直达文档的编撰人员，解决后也会收到Lark提醒。

* **获取Lark开放能力的更新信息**：来[更新日志](https://open.larksuite.com/changelog)了解新发布的开放能力
  
* **加入开发者社群**：想获取最新能力的内测机会，并与其他企业开发者交流，欢迎你加入[Lark开发者社群](https://applink.larksuite.com/client/chat/chatter/add_by_link?link_token=9c9v4db7-e72f-4f7e-9178-daf25279088t)。
