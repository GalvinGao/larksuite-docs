# 打开任务
::: note 
从Lark 4.6.0 版本开始支持。
:::

## 使用场景
打开任务首页，查看任务。

**什么是「任务」**：任务是一个轻量级的团队任务管理工具，可有效帮助成员：集中管理任务、追踪任务进度、推进团队协作。
## 协议
[https://applink.larksuite.com/client/todo/open](https://applink.larksuite.com/client/todo/open)

##  参数
无
