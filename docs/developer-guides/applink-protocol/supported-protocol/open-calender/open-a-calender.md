# 打开日历
::: note 
从Lark 3.40.0 版本开始支持。
:::

## 使用场景
跳转并打开日历，打开界面为上一次离开日历时的视图。

## 协议
[https://applink.larksuite.com/client/calendar/open](https://applink.larksuite.com/client/calendar/open)
