# 打开云文档
::: note 
从Lark 3.22.0 版本开始支持。
:::

## 使用场景
打开云文档（docs）。使用外部浏览器打开文档时，提供入口从Lark中打开。

## 协议
::: note 
PC端不支持（PC端推荐直接使用文档链接）。
:::
`https://applink.larksuite.com/client/docs/open`

## 参数

| 字段         | 必填           | 说明        | 
| --------- | --------------- | -------   | 
|URL | 是         | 要打开的云文档URL | 



## 使用示例
打开一个云文档

`https://applink.larksuite.com/client/chat/open?openId=1234567890`
