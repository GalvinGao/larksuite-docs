# 步骤四：体验机器人

:::note
对于测试版应用来说，仅测试企业的 **创建者** 及 **测试人员** 可以访问该应用。
:::
  
1. 打开**Lark客户端**，搜索**机器人名称**，点击进入机器人对话框。
      
:::note
若机器人应用没有出现对话框，请确认是否开启机器人能力。
:::

![image.png](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/23cd3d38f46a887ada29a79f7e5d00e4_8nZpJG4jr6.png?height=530&lazyload=true&maxWidth=600&width=1114)
    

2. 在机器人对话框中发送任意消息，可体验机器人自动回复。
