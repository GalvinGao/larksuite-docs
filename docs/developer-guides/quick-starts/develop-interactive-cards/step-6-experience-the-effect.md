# 步骤六：体验效果

完成上述步骤后，您可以在Lark客户端中体验审批机器人的功能效果。

## 操作步骤

1. 在Lark客户端中搜索 **应用名称**（示例中为「审批机器人」），点击进入聊天窗口。

	![](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/5dd4f9a776b1ec5c9d82f319b49867f5_KQEKVXwPkm.png?height=482&lazyload=true&maxWidth=600&width=1894)

2. 发送「**审批**」消息后，在自动回复的审批卡片上点击 **请假** 或 **加班** 按钮，查看卡片回复。

	![消息卡片结果展示.gif](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/d634a018c974f35c299b7eb9623c257c_Djf576U7AY.gif?height=1426&lazyload=true&maxWidth=600&width=1454)
