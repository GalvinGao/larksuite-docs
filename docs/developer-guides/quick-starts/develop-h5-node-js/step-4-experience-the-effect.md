# 步骤四：体验效果

本章节以移动端体验效果为例进行介绍，您也可以使用桌面端体验网页应用效果。

:::note
对于测试版应用来说，仅测试企业的 **创建者** 及 **测试人员** 可以访问该应用。
:::

1. 使用移动端登录Lark，并进入Lark工作台打开测试应用。
   
   ![](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/ed135a765938b93cd0f0cb3c48f64121_7f59oZqetr.png?height=1202&lazyload=true&maxWidth=300&width=582)
   
2. 使用应用。

   示例应用提供了三个接口能力。
   
   ![](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/9d348fdae8f6de9874aa83fb05c2345a_QESLvn9Ijv.PNG?height=2532&lazyload=true&maxWidth=300&width=1170)
   
   - 点击 **JSAP - getSystemInfo**，查看本机信息。

     
   - 点击 **JSAPI - showActionSheet**，查看示例选项卡。
   
     
   - 点击 **JSAPI - previewImage**，查看示例图片。
