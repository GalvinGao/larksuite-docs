# 如何获取应用的 App ID

## 1. 打开Lark开放平台开发者后台，选择需要查看 App ID 的应用

打开[Lark开放平台开发者后台](https://open.larksuite.com/app?lang=zh-CN)，找到需要复制 App ID 的应用，点击并打开应用详情页。


![image.png](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/64f255fd55baffd2b08e573731fd0453_pd4CoLTTVN.png?lazyload=true&width=2275&height=1489)

## 3. 打开「凭证与基础信息」页面并复制 App ID

在应用详情页点击左侧的「凭证与基础信息」，切换至「凭证与基础信息」页面。

![image.png](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/3041d8724e893969ee109bcdb79dc018_y09gXA3Ytx.png?lazyload=true&width=3001&height=1157)
在该页面顶部的「应用凭证」中可以找到具体的 App ID。点击 App ID 右侧的按钮可以复制该应用 App ID。


![image.png](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/60716d61cb5afb867f38ddbcba305326_XbtHxBAZma.png?lazyload=true&width=2477&height=959)
