# 如何启用机器人能力


## 1. 打开开发者后台

通过链接访问[Lark开放平台开发者后台](https://open.larksuite.com/app)，或点击右上角**开发者后台**进入Lark开放平台开发者后台。


![Vector.png](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/e421c5103732ad23b89ec477743e6e7e_yVC1m3I38a.png?height=1122&lazyload=true&width=3582)

## 2. 选择需要启用机器人能力的应用

在Lark开放平台开发者后台选择要开启机器人能力的应用，点击应用名称，进入到应用的管理页面。

![image.png](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/f485799371a6baac151b42163f35630e_YtQMeH6uPU.png?height=782&lazyload=true&width=1920)

## 3. 开启机器人能力

在应用管理页面，点击**添加应用能力**，并在添加应用能力页面点击机器人卡片中的添加能力按钮，添加该能力。

![image.png](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/a25e5da5199db7920e847bde601a8a5d_DfDyfp3Rur.png?lazyload=true&width=1544&height=626)
