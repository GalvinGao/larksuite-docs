# 典型案例

本文提供部分卡片案例供你参考，你可以根据案例构建符合自己业务需求的卡片内容。

:::note
构建所需的卡片内容，需要使用消息卡片搭建工具。详情参考[消息卡片搭建工具概述](/document/ukTMukTMukTM/uYzM3QjL2MzN04iNzcDN/message-card-builder)。
:::

## 通用案例

| 案例 | 描述 | 富文本效果图 | 单独链接效果图 |
| --- | --- | --- | --- |
| 长文类 | 当链接指向概述、方案、教程等文本内容较多的网页时，可以配置卡片展示网页的内容概要。 | ![image.png](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/4f9715f2bd34a9f50009503a46505e73_44R30AAphw.png?height=882&lazyload=true&width=1124) | ![image.png](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/5529649e4acace5652e345b85cf7439a_IsBzobdfQy.png?height=682&lazyload=true&width=1122) |
| 文档类 | 如果链接是云文档，或者其他包含业务操作的文档，可以通过卡片展示网页的内容概要，并配置简单的交互逻辑，用于在卡片内完成业务操作。 | ![image.png](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/9926147a0925ed78eb6f12f1444dc3f3_RNC2F7BmlE.png?height=904&lazyload=true&width=1124) | ![image.png](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/aa88968623bb481dff7f381c50d1507e_qET8HM2tKV.png?height=804&lazyload=true&width=1076) |
| 直播类 | 如果链接指向的是直播间，则可以通过卡片展示直播信息，并配置简单的交互逻辑，实现预约直播等操作。 | ![image.png](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/60edbbfc6ea1a8ab7357efb9621d7058_tn24aefXzp.png?height=982&lazyload=true&width=1124) | ![image.png](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/7ba56a161248faf608fb73bcf7588046_63P4daC8VP.png?height=882&lazyload=true&width=1076) |
| 应用类 | 如果链接是Lark应用，或者企业内的其他应用，则可以通过卡片展示应用的图标、简介等信息。 | ![image.png](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/6f7a96a513cd46f40385f7b3ff23c008_UciCl9pamg.png?height=440&lazyload=true&width=1070) | ![image.png](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/3009dfeb8a16fc0b60d74abd48d7fb32_xEkc4jQBN1.png?height=286&lazyload=true&width=1108) |
