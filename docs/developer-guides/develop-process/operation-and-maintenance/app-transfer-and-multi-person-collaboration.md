# 应用转移与多人协作
  
在应用的开发过程中经常会遇到人员调整，你可以通过转移应用所有权和多人协作功能来随时调整开发人员。

:::note
该功能仅支持正式版应用，测试版应用或测试企业不支持该功能。
:::

## 转移应用所有权

1. 登录 [开发者后台](https://open.larksuite.com/app)，点击进入应用详情页，在 **凭证与基础信息** 页面，点击 **转移应用所有权**。

3. 在弹出窗口中输入所需账号，选中目标人员后，点击 **确认转移** 即可。

	![](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/d006cdd0b9e308fe9a8527d4ac0f402d_Ur4bkQvtFr.png?height=444&lazyload=true&maxWidth=600&width=1174)

	转移成功之后可以收到来自**Lark** **开发者小助手**的应用转移通知。

	![](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/5084a588604ef4f605909213f3af2cf1_vc33aBIMeH.png?height=364&lazyload=true&maxWidth=600&width=1366)

## 多人协作

在同时有多个人员共同开发和配置应用的情况下，你可以把相关人员加入到应用的 **成员管理** 列表中。


1. 登录 [开发者后台](https://open.larksuite.com/app)，点击进入应用详情页，选择进入 **成员管理** 页面，点击 **添加协作人员**。

    ![image.png](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/c9bc7d93e9497751f527d0b3a7eeec52_qxeDpngEaL.png?height=1044&lazyload=true&maxWidth=600&width=2786)

2. 在弹出窗口中，添加协作人员并选择合适的角色。

	不同角色所具备的权限不同。


    ![image.png](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/dee50da5b71bb2dd83b9e96a35898503_CZlqSUjfnM.png?height=1352&lazyload=true&maxWidth=500&width=1178)

    添加完成之后即可在 **成员管理** 列表中看到新加入的成员，并可进行修改及移除角色。

    ![image.png](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/a363ab244dc85943e9796bf34a50ee53_KtSO8wgwb9.png?height=532&lazyload=true&maxWidth=600&width=2396)

    被添加的新成员也会收到来自**开发者小助手**的通知。
    
    ![](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/ce68dafea1fa08e272b79ca71fe41f89_K2wGwRGhkR.png?height=722&lazyload=true&maxWidth=600&width=1458)
