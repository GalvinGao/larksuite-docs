# 二、创建商店应用

当企业获取 ISV（独立软件服务商）资质后，开发者就可以在开发者后台创建商店应用。

## 操作步骤
1. 在 [开发者后台](https://open.larksuite.com/app) 页面点击 **创建商店应用** 按钮。

	![图片](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/e057380527ccdec9ab2420bd9ce10dea_K141JQhLHR.png?height=618&lazyload=true&maxWidth=600&width=2448)

2. 填写应用 **名称**、**应用描述**，选择或上传 **应用图标**，并点击 **创建**。

	![图片](https://sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/bbcbe37b22b02736e20d60c9df2a8732_6Djn3ETbaH.png?height=1322&lazyload=true&maxWidth=400&width=1206)

应用创建成功后，会自动跳转到应用能力页面，你可以根据业务需求为应用开通不同的应用能力。更多介绍，参考[应用能力简介](/document/home/app-types-introduction/robots-web-applications-and-mini-programs)。
