# 真机预览

Block 已在Lark文档和工作台中应用，开发者工具提供了 Block 在Lark文档、工作台 PC 及移动端的预览功能。

## 云文档预览

当宿主选择是云文档时，开发者可以提供一个文档链接用于预览。若不提供则工具会创建一篇测试文档。


![image.png](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/435f3e4ad83152bf9df90229b1fa55ad_UZROdvLxI5.png?lazyload=true&width=886&height=764)

点击 **立即预览** 后，开发者工具会打开该文档，通过文档加号菜单可插入需要预览的 Block，并点击 **调试构造器** 即可预览本地 Creator 代码，或 **读取本地资源** 预览本地 Block 代码。



![image.png](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/324e4790154c8a78145afccb03c9d342_csLJPYShQz.png?lazyload=true&width=1640&height=1226)

## 工作台预览

当宿主选择是工作台时，开发者点击 **立即预览** 按钮即可在PC 端或移动端预览。此时开发者的Lark客户端会收到消息卡片，点击后即可预览 Block。


![image.png](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/e664e640cf0c1748283fa082f86fd34c_Xu5gjxwqlm.png?lazyload=true&width=932&height=440)

## 上传

点击 **上传** 按钮，并填写版本号信息即可上传 Block 程序包。


![image.png](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/f6102d868385aebd909e210230ad039d_bxsAkJMMxP.png?lazyload=true&width=972&height=1480)

上传完成后，前往 **Lark开放平台**，点击 **应用功能**，选择 **小组件** ，并选择刚才上传的版本。完成填写后需要发布应用才可生效。


![image.png](//sf16-sg.larksuitecdn.com/obj/open-platform-opendoc-sg/f7330b6dfbcdb52b095ce3b7188f6cc2_tZZyoKH1yq.png?lazyload=true&width=1640&height=1285)
