# 基本介绍

小程序自动化 SDK 结合 CLI 开发者工具，提供了一套操作小程序的 API。通过这套 API 可以完成小程序的自动化测试。

## 主要功能
通过该SDK，你可以做到以下事情：

* 作为自动化测试模块，集成于 CI 环节
* 控制小程序页面路由
* 获取小程序页面
* 获取小程序页面元素
* 模拟点击事件
* 获取评分
* ...
