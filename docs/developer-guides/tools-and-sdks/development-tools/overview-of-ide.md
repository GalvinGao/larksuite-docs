# Lark 开发者工具

为了帮助开发者更便捷地开发 Lark 应用，我们升级推出 Lark 开发者工具，从安装方式、视觉、交互、性能、功能完备度等方面全方位升级。

目前已经支持的功能包括：

> * 小程序的调试、预览和发布。**注：小程序包大小不能超过10M**
> * 网页应用的调试、预览
> * 编辑器和资源管理器
> * 内置命令行工具
