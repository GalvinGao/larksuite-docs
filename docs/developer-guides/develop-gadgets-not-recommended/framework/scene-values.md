# 场景值
场景值描述了用户打开小程序的路径。小程序在客户端打开有多种场景。

## 获取场景值
开发者可以通过以下方式获取场景值：
在`App`的`onLaunch`和`onShow`的`options`参数里可以拿到`scene`，或者调用`tt.getLaunchOptionsSync `得到的返回值里获取scene
