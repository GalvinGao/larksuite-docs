# 概述
整个小程序框架系统分为两部分：逻辑层（App Service）和 视图层（View）。小程序提供了自己的视图层描述语言 **TTML** 和 **TTSS**，以及基于 JavaScript 的逻辑层框架，并在视图层与逻辑层间提供了数据传输和事件系统，让开发者能够专注于数据与逻辑。下面会从小程序的场景值、逻辑层、视图层等方面进行说明，帮助大家更好地理解小程序的开发要点。
