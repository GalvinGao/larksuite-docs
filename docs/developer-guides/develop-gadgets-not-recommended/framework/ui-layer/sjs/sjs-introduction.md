# 简介

sjs 是指 `Safe JavaScript`，是小程序一套自定义脚本语言，可以在 TTML 模版中使用，主要使用场景是对插值表达式中的变量进行处理，类似于过滤器函数。sjs 的语法是 JavaScript 的子集，但请不要将 sjs 等同于 JavaScript。

有关 sjs 的更多内容，请点击左侧目录查看。
