# 资源介绍
 “角色”指的是Lark管理后台“角色管理”模块中的“角色”概念。目前主要应用于审批场景，指的是团队成员的专业分工类别，可由 1 位或多位成员组成，如人事、行政、财务等。角色的唯一标识是“role_id"，租户下唯一。
