# 新建文件夹

在用户云空间的指定文件夹中创建一个新的空文件夹。{尝试一下}(url=/api/tools/api_explore/api_explore_config?project=drive&version=v1&resource=file&method=create_folder)

:::html
<md-alert type="error">

</md-alert>
:::

:::html
<md-alert type="warn">
该接口不支持并发创建，且调用频率上限为 5QPS 以及 10000次/天
</md-alert>
:::

<md-alert type="tip">

</md-alert>
