# 删除知识空间成员

此接口用于删除知识空间成员。

- 公开知识空间（visibility为public）对租户所有用户可见，因此不支持再删除成员，但可以删除管理员。

- 个人知识空间 （type为person）为个人管理的知识空间，不支持删除管理员。但可以删除成员。{尝试一下}(url=/api/tools/api_explore/api_explore_config?project=wiki&version=v2&resource=space.member&method=delete)
