### 错误码

| HTTP状态码 | 错误码 | 描述 | 排查建议 |
| --- | --- | --- | --- |
| 404 | 1184000 | 企业不存在 | 确认tenant_access_key是否正确 |
| 403 | 1184001 | 无权限获取企业信息 | 如果ISV应用是预装的并且180天内企业未使用过此应用，则无法通过此接口获取到企业信息 |
