# 部门维度的数据报表

即按照部门维度聚合的数据，统计的是该部门下直属用户的数据，包含了部门维度的用户数据（新增/离职人数，新增活跃人数等）以及该部门的功能使用数据。当天的数据会在第二天的早上八点产出（UTC+8）。

## 方法

**[获取部门维度的用户活跃和功能使用数据](/document/uAjLw4CM/ukTMukTMukTM/reference/admin-v1/admin_dept_stat/list)**

&emsp;&emsp;该接口用于获取部门维度的用户活跃和功能使用数据，即IM（即时通讯）、日历、云文档、音视频会议功能的使用数据。
