# 抄送审批实例

调用该接口将当前审批实例抄送给指定用户。被抄送的用户可以查看审批实例详情。例如，在Lark客户端的 **工作台 > 审批 > 审批中心 > 抄送我** 列表中查看到审批实例。{尝试一下}(url=/api/tools/api_explore/api_explore_config?project=approval&version=v4&resource=instance&method=add_cc)
