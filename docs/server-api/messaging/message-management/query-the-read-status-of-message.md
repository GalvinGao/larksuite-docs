# 查询消息已读信息

查询消息的已读信息。{尝试一下}(url=/api/tools/api_explore/api_explore_config?project=im&version=v1&resource=message&method=read_users)

</md-alert>

:::html

:::html
<md-alert type="tip">
注意事项:
- 需要开启[机器人能力](/document/uAjLw4CM/ugTN1YjL4UTN24CO1UjN/trouble-shooting/how-to-enable-bot-ability)  
- 只能查询机器人自己发送，且发送时间不超过7天的消息
- 查询消息已读信息时机器人仍需要在会话内
- 本接口不支持查询批量消息
</md-alert>
:::
