#  概述

数据驻留服务可以帮助企业管理其数据的驻留位置。开通数据驻留服务后，可以通过相关 OpenAPI 来使用该服务。例如可以设置用户（即员工）的数据地理位置，设置成功后，用户相关数据会驻留到指定的地理位置。
