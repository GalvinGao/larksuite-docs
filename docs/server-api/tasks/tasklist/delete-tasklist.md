# 删除清单

删除一个清单。

删除清单后，不可对该清单做任何操作，也无法再访问到清单。清单被删除后不可恢复。{尝试一下}(url=/api/tools/api_explore/api_explore_config?project=task&version=v2&resource=tasklist&method=delete)

:::html
<md-alert type="tip">
删除清单需要清单管理权限。详情见[清单功能概述](/document/uAjLw4CM/ukTMukTMukTM/task-v2/tasklist/overview)中的“清单是如何鉴权的？“章节。
</md-alert>

### 错误码

| HTTP状态码 | 错误码 | 描述 | 排查建议 |
| --- | --- | --- | --- |
| 400 | 1470400 | 请求参数错误 | 错误原因见返回的msg提示的信息。 |
| 404 | 1470404 | 清单不存在或者已删除。 | 确认要删除的清单是否存在或已删除。 |
| 500 | 1470500 | 服务器错误。 | 尝试重试调用。如持续失败，请联系支持人员进行反馈。 |
| 403 | 1470403 | 缺少清单的所有人权限。 | 检查调用身份是否有任务的所有人权限。详情见[清单功能概述](/document/uAjLw4CM/ukTMukTMukTM/task-v2/tasklist/overview)中的“清单是如何鉴权的？“章节。 |
