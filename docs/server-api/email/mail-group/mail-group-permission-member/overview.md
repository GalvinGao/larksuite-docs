# 邮件组权限成员资源

邮件组权限成员资源







## 方法

**[创建邮件组权限成员](/document/uAjLw4CM/ukTMukTMukTM/reference/mail-v1/mailgroup-permission_member/create)**

&emsp;&emsp;向邮件组添加单个自定义权限成员，添加后该成员可发送邮件到该邮件组。

**[获取邮件组权限成员](/document/uAjLw4CM/ukTMukTMukTM/reference/mail-v1/mailgroup-permission_member/get)**

&emsp;&emsp;获取邮件组单个权限成员信息。

**[批量获取邮件组权限成员](/document/uAjLw4CM/ukTMukTMukTM/reference/mail-v1/mailgroup-permission_member/list)**

&emsp;&emsp;分页批量获取邮件组权限成员列表。

**[删除邮件组权限成员](/document/uAjLw4CM/ukTMukTMukTM/reference/mail-v1/mailgroup-permission_member/delete)**

&emsp;&emsp;从自定义成员中删除单个成员，删除后该成员无法发送邮件到该邮件组。
