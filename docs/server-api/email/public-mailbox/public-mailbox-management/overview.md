# 公共邮箱资源

公共邮箱资源







## 方法

**[创建公共邮箱](/document/uAjLw4CM/ukTMukTMukTM/reference/mail-v1/public_mailbox/create)**

&emsp;&emsp;创建一个公共邮箱。

**[查询指定公共邮箱](/document/uAjLw4CM/ukTMukTMukTM/reference/mail-v1/public_mailbox/get)**

&emsp;&emsp;获取公共邮箱信息。

**[查询所有公共邮箱](/document/uAjLw4CM/ukTMukTMukTM/reference/mail-v1/public_mailbox/list)**

&emsp;&emsp;分页批量获取公共邮箱列表。

**[修改公共邮箱部分信息](/document/uAjLw4CM/ukTMukTMukTM/reference/mail-v1/public_mailbox/patch)**

&emsp;&emsp;更新公共邮箱部分字段，没有填写的字段不会被更新。

**[修改公共邮箱全部信息](/document/uAjLw4CM/ukTMukTMukTM/reference/mail-v1/public_mailbox/update)**

&emsp;&emsp;更新公共邮箱所有信息。

**[删除公共邮箱](/document/uAjLw4CM/ukTMukTMukTM/reference/mail-v1/public_mailbox/delete)**

&emsp;&emsp;该接口会永久删除公共邮箱地址。可用于释放邮箱回收站的公共邮箱地址，一旦删除，该邮箱地址将无法恢复。
