# 开发文档检索 MCP 概述

开发文档检索 MCP（后续简称“文档检索 MCP”）使用 MCP（Model Context Protocol） 协议连接Lark开放平台，用于检索[Lark开放平台开发文档](/document/home/index)。与 AI agent 集成后，可根据你的诉求检索相匹配的开发文档内容，并结合项目上下文自动生成代码示例。具体使用说明参见[安装并使用文档检索 MCP](/document/uAjLw4CM/ukTMukTMukTM/mcp_integration/install-and-use-document-search-mcp)。

## 场景示例


通过向 AI 发送诉求，如`如何搭建Lark卡片并将卡片发送给指定用户？`，获取开发文档以及示例代码。
